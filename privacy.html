Privacy and handling

Your repository stays local by default.

Clear handling rules for source code, credentials, audit artifacts, and third-party tools.

Repository processing

Customer repositories are reviewed in a local working environment by default. Source code is not intentionally uploaded to an AI model or unrelated third party without separate written permission.

Credentials

Customers should never place passwords, API keys, private keys, or production credentials in intake documents or ordinary email. If temporary access is required, it must be limited, transferred through the agreed secure channel, and revoked after delivery.

Third-party tools

Package registries and explicitly agreed scanners may receive package names, dependency manifests, requests, or other information required for their function. Tools used are recorded in the audit report. Customer source code is not intentionally sent to those services unless separately disclosed and approved.

Redaction

Secret-like values are redacted from generated reports. Raw logs and static matches are reviewed before customer delivery.

Retention and deletion

Unless otherwise agreed in writing, working repository copies and unreviewed logs are deleted within 14 days after delivery. Final reports and necessary administrative records may be retained for up to 90 days.

Public examples

Published demonstrations use synthetic applications and redacted evidence. Customer repositories, findings, names, and reports are never used as public examples without explicit permission.

Contact

Questions about this notice or repository handling can be sent to tripexsupport@gmail.com. The pilot is operated by Raven Ho, TRIPEX founder.

Important: This privacy statement describes the pilot’s operating practice. It is not a compliance certification or legal opinion.
